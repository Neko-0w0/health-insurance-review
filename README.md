# 115 健康保險技術員 考前複習

單一 HTML 檔的考前複習網頁，內容整理自《115 健康保險技術員 考前複習筆記》。

- **筆記**：11 個單元、47 個小節，含必背／易混／口訣框，可切換「只看必背」
- **測驗**：112 年考古題 75 題＋資安自擬 6 題；章節練習、錯題本、模擬考（專業 50 題 60 分鐘、實務單選 25 題 25 分鐘）
- **簡答閃卡**：18 題簡答參考答案
- **復習日曆**：10/29–12/19 每日任務與簽到（考試日 115/12/20）

## 使用

直接用瀏覽器開啟 `index.html`，或開啟 GitHub Pages。簽到、已讀、作答紀錄存在瀏覽器的 localStorage，只保留在同一台裝置與瀏覽器。
